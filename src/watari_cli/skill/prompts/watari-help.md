---
description: ワタリの使い方をやさしく説明する
---
ワタリの使い方を、次の内容で簡潔に（10 行程度で）説明してください。内部用語は使わないこと。

- ワタリは会話から「あとで役に立つこと」（決めごと・予定・好み・学んだことなど）を少しずつ覚えていく相棒であること。
- 記憶はこのパソコンの記憶フォルダに保存され、いつでも確認・削除できること。パスワードなどの秘密そのものは覚えないこと。
- 使えるコマンド: /remember（確実に覚える）・/organize(記憶の整理を今すぐ)・/profile（覚えている内容の確認）・/forget（忘れる）・/goal（この会話の目標を決める）。「記憶を整理して」と話しかけても整理できること。
- Gmail やカレンダーなどのサービスを繋ぐと、そこからも覚えられること（ターミナルで `watari connect` を実行。メニューが出ます）。
- モデルの切り替えや API のログインは Pi 側の機能であること（`/model`・`/login`）。
- 最後に、記憶の様子はターミナルの `watari status` で確認できることを添える。
